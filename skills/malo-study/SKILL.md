# malo-study —— 学习阶段

**不判达标、不做整套卷。** 只做三件事：按图过材料、每点播种 1–2 次样本、产出「不熟清单」。

## 0 · 版本闸

读 `sys/config.json` 的 `schema_version`，与 `../_shared/scripts/_lib.mjs` 的 `LIB_VERSION` 比；不一致就停，指回 CHANGELOG 迁移。

## 1 · 范围（一次一问）

- 问用户：**这次学到哪**（分类里的一个或多个类路径，例：`深度学习/L4 优化技术`）。
- **前置闭包**：从范围内的点出发，沿 `sys/graph.json` 的前置边递归；
  - 遇到 `是否学习过 = 是` 就**停**，不再展开它的前置；
  - 成员判定看点的**任一** `分类` 命中本次范围；
  - 按**笔记名**去重，一个点只算一次。
- 跨课程前置会被拉进来；它们只要求「学过」，**不纳入达标**（达标归 `/malo-quiz`）。

## 2 · 顺序

```bash
node ../_shared/scripts/graph.mjs check <根> --layers --write
```

读 `sys/layers.json`：

- 从**层 0** 开始往上（`layers.json` 的 `layers[0]` 就是层 0，不是「第 1 层」）；
- 同一层内按 `分类`（讲次）聚批；**第一次遇到某讲时，把该讲讲义整份解析一次并留在上下文**，之后同一讲的点即使在不同层，也直接引用，不重复解析；
- 若 `graph.json` 有 `groups`（OR 前置），闭包按组规则：组内任一满足即可，不要求全学；
- 已学过（`是否学习过 = 是`）的点跳过。

## 3 · 每点怎么过

1. 读该点笔记 + `## 讲义出处` 标的页；源文件在 frontmatter 的 `归属`。
2. 出 **1 题**，题后挂 `答案：` / `思维链：` 两行；用户必须写思维链。
3. 判：思维链对且答案对 = 做对；否则 = 错。
4. **错** → 回读该点 `讲义出处` 那几页 → 出**第 2 题**。
5. 两题结束（或第一题就对）：`是否学习过 = 是`，按增量写账本。

写账本：

```bash
node ../_shared/scripts/ledger.mjs write <根> <updates.jsonl>
```

一行一条：

```json
{"知识点":"梯度","做对":1,"总共出过":1,"是否学习过":true,"最后复习日期":"2026-11-08"}
```

## 4 · 不熟清单

不落盘，按**本次学习**算：**本次两题全错的点**（第一题对 → 不在；第一题错、第二题对 → 不在；两题都错 → 在）。在对话里维护这张表，结束时给用户。

给用户一张小表：知识点 / 出过 / 做对 / 在哪一讲 / 讲义页。这张表就是「先读哪些」的清单。

## 5 · 停止与恢复

- **停止**：本次范围学完，或用户说停。
- **恢复**：重新跑时，跑
  ```bash
  node ../_shared/scripts/ledger.mjs next <根> [--scope <本次范围>] [--n 5]
  ```
  它按 `layers.json` 的层序 + `ledger.jsonl` 的 `是否学习过` 现场对齐，直接给出「第一个没学过的点」；从它继续，不需要另存进度。

## 6 · 闸门

- `config.闸门.study开局`（默认 `每次`）：开始前给范围 + 拓扑顺序里的前 N 个点。
- `config.闸门.study单点`（默认 `从不`）：每个点问不问，默认不问，避免 451 个点被打断死。

## 7 · 不要

- 不判「达标」「样本不足」——那是 `/malo-quiz` 的事。
- 不自动补写笔记内容；不熟只记录，不下判断。
- 不碰 `kb/MOC/` 的手写区。
