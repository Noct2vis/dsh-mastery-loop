# 错误原因表

> ⚠️ **本文件由 `mastery-loop` 维护。**
> 是**真值**（错误历史只在这里），**删掉无法重建**。

## 两条铁律

1. **表述必须逐字一致才能被统计。** 同一个偏移犯三次，三次必须命中**同一条**。
   新增前先**在该知识点分组内全量检索**：语义相同 → **复用原句、只追加日期**，**不许重新措辞**。
2. **复合错误要拆分。** 一次作答里错了思维链又错了答案 → **两条**。

## 写法（错误原因用英文）

按 **ASD-STE100** 的规则写（`mastery-loop` 声称的是「尽可能按 STE 规则写」，**不是**「符合 ASD-STE100」）：

- 句式优先 **`把 A 当成 B`**（概念混淆类）；其余用 **`<动作> + <对象>`**
- **一句只写一个偏移** —— 出现 `and / but / because / so / then` 就是两个命题，必须拆
- **不超过 20 词**（Rule 5.1）；**名词短语不超过 3 词**（Rule 2.1）
- **不写**：题号、具体数字、时间词（`today / last time`）、第一人称、情绪词（`careless`）
- **动词开头**，且**必须带对象**（禁 `wrong`、`didn't know` 这种空动词）
- **指代不悬空** —— `it / this / the former` 必须在同一行找得到所指
- **「概念混淆」必须写出 A 和 B** —— 只写 `concept confusion` 等于没写

## 结构（**先按知识点分组，再按错误原因分组**）

```markdown
# 错误原因表

## [[核技巧]]

### forgot to normalise before comparing
- 2026-10-09
- 2026-10-11

### treated explicit inner product as the kernel value
- 2026-10-11

## [[梯度]]

### took steepest ascent for steepest descent
- 2026-10-09
```

## 维护规则

- **去重键 = 知识点 + 错误原因** → 同一句话在两个知识点上**各自成条**
- 重复出现 → **只在该条目下追加日期**，不新增条目
- **单个知识点上限 60 条**；超了就该回头归纳，把类别写进 `error-taxonomy.md`
