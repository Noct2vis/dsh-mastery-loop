# 卷子格式

> ⚠️ **生成卷子时从这里查对应考试的那一条** —— `mastery-loop` **不再每轮从往年卷现抄参数**。
> 由 `mastery-loop-setup` 在首次初始化时生成；**有变动时读**。

## 结构：**每个课程的每个考试各一条**

（期中 / 期末 / in-class / coursework 形状不同，必须分开）

## <课程名>

### <考试名>

- **时间**：<分钟>
- **总分**：<分>
- **题数**：<题>
- **题型**：<判断 / 定义 / 计算 / 画图 / 证明 / 简答…>
- **分值分布**：<…>
- **来源**：<抄自哪份往年卷；或「**无往年卷 → 用默认出卷法**」>

### <考试名>

…

## 没有往年卷时：默认出卷法

**判断题 + 每题说明理由。**
（这也正好接上思维链要求 —— 「说出为什么」就是思维链。）

> 📌 优先**问用户**该怎么办；用户没有更好的主意时，用上面这个默认。
