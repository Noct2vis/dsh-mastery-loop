# mastery-loop 初始化

> **本文件是初始化 / 迁移流程。** 契约正文（*库长什么样、每个文件干什么*）在
> [`../mastery-loop/templates.md`](../mastery-loop/templates.md) —— **它是权威，改契约只改那里**，本文件只讲「怎么建」。

**产出：两个并列文件夹**

| 路径 | 是什么 |
| --- | --- |
| `kb/knowledge/` | 知识点笔记（一篇一个知识点） |
| `kb/MOC/` | 聚合产物，镜像分类层级（每层一份索引 + 叶子层讲次 MOC） |
| `sys/config.json` | 设定：路径 / 分类 / 语言 / 确认标记 |
| `sys/graph.json` | 关系图（前置关系的真值） |
| `sys/ledger.jsonl` | 账本（逐知识点复习统计，真值） |
| `sys/errors.jsonl` | 错误原因表 |
| `sys/error-taxonomy.json` | 失分原因分类（初始为空，agent 维护） |
| `sys/paper-format.json` | 卷面参数 |
| `sys/state.jsonl` | 状态（哈希 / schema 版本 / 检查时间） |
| `sys/changes.jsonl` | 变更流水 —— **只在没有 git 且用户不装 git 时才建** |

> 这是 **prompt-driven skill，不是确定性脚本**。探索、把发现摆出来、问、确认，然后才写。

---

## 0 · 硬规矩

- **材料目录只读。** 不改、不移、不改名用户给的任何课程材料。
- **结构可重建，内容原样搬运。** 重建的只是 frontmatter 字段集、正文固定小节、链接写法、MOC / 索引；**内容是用户的**（一句话 / 核心内容 / 易错点 / 讲义出处），一个字节不动。
- **改什么先给清单。** 动手前先把「哪篇要动、动什么」摆给用户过目。
- **幂等。** 第二次跑必须零改动 —— 合规的文件**不重写**。
- **问出来的信息要留痕**：`（用户于 <YYYY-MM-DD HH:MM> 确认）`，就地只留最新一条。
- **不含任何真实路径进 skill 包** —— 真实路径只写进用户的 `sys/config.json`。
- **不自动 `commit`、绝不 `push`。**

---

## 1 · Explore（先看，别假设）

- **材料**：先列用户给的目录里**实际有什么**，不套固定清单（各课结构不同，有的课压根没有往年卷）。
- **既有笔记库**：有没有已经成形的知识库？知识点在哪个目录？frontmatter 有哪些字段？正文有哪些小节？
- **是否已经初始化过**：`sys/` 在不在？**在就先停下问用户**「要重新初始化，还是只补缺的」。
- **git**：工作区是不是 git 仓库？（决定用 git 还是回退到 `sys/changes.jsonl` 记历史）

### 1.1 合规扫描（**agent 做，不能脚本化** —— 初见的库状态无法预料）

逐篇看三件事，产出清单：

| 看什么 | 合规 |
| --- | --- |
| frontmatter 字段集 | `类型` / `归属`（来源文件，多值）/ `aliases` / `标签`；**没有** `课程:` / `主题:` / `难度:` |
| 正文小节 | `一句话 / 核心内容 / 前置知识 / 后置知识 / 易错点 / 考点 / 讲义出处`；**没有 `## 平行关联`** |
| 链接写法 | 带路径、相对工作区根、带后缀、带别名 |

**合规的 → 一行不动**；不合规的 → 只改结构、内容原样搬。清单交给用户确认后再动（§6）。

---

## 2 · 分类与范围（**必问，不默认推荐**）

**分类是全库级定义**，层数和每层有几个类都不固定。

1. **先扫一遍材料**，给出一版候选建议（例如「你这里看起来是按『课程 → 讲次』分的」）；
2. **问用户「按什么分类」** —— 用户可能不是按上课学的（比如「书 → 章」），**不要预设课程**；
3. **问用户「每一层具体怎么认」** —— 得到**解析规则**（例：课程 = 来源路径第一层文件夹名；讲次 = 文件名里的 `W1L3`）；
4. 用户校正后，把**层级 + 每条解析规则 + 每层类值（+ ASCII slug）**写进 `sys/config.json`，并带确认标记；
5. **范围**：用户说「整理某部分」时，**从分类里选**（一个或多个类值）。不同范围**共用同一套分类**。

---

## 3 · 素材：两个类别

**必需的只有两个类别**，不是两个确定的文件：

| 类别 | 用来 | **默认成员** | 类里其他合格成员 |
| --- | --- | --- | --- |
| **建库参考** | 建知识库 | **讲义** | 教学大纲 / exam_topics / 课件 / 教科书章节 |
| **出题参考** | 出题与判分 | **往年试卷** | 往年卷答案 / Lab sheet / Worksheet / Assessment 结构 |

**判定分两级**：① **某一类整类为空** → 真缺，告诉用户缺什么、去哪找；② **类里有内容但没默认成员** → **不算缺**，问一句「用类里另一样顶吗」。

**换成员必须问**，定了记进 `sys/config.json`（带确认标记），之后不再问。同时问一句：**「有没有你不想让我读的？」**

---

## 4 · 语言标准

**按 6 个产物类别分别问**（用户可以用自然语言回答，如「全都中英双语对照」）：① 知识点笔记（正文 / 标题 / `aliases` / MOC）② 出的题 ③ 批改与解析 ④ 记录性文件 ⑤ 产出（复习清单 / 考前 list）⑥ 机制层（字段名 / config）。

> ⚠️ **`sys/errors.jsonl` 里的错误原因默认用英文** —— 它要套 ASD-STE100 的规则，不跟别的类别走。
> 📌 **不要预设双语。**

---

## 5 · 卷面格式

**每个课程的每场考试各一条**（期中 / 期末 / in-class / coursework 形状不同，必须分开），落进 `sys/paper-format.json`：时间 / 总分 / 题数 / 题型 / 分值分布，并**记住来源**（抄自哪份文件）。

**没有往年卷时**：先问用户；用户没更好的主意 → 用**默认出卷法 = 判断题 + 每题说明理由**，并在该条写明。

---

## 6 · 重建（合规检查 → 清单 → 动手）

1. **先按 §1.1 逐篇判定**，把清单摆给用户（哪篇要动、动什么、为什么）；
2. 用户点头后，**按分类分层一块一块做**（例：先 DL L1，做完跑校验，再下一块）；
3. **安全网**：有 git → 提示用户先 commit；没有 git → 先把 `kb/` + `sys/` 复制一份到工作区外的备份目录再动手；
4. 重建内容：frontmatter 字段集 · 正文小节顺序 · 链接改写 · MOC / 索引；
5. **`## 平行关联` 里的链接不要丢** —— 转成 `sys/graph.json` 里的边（判据仍按契约第二节）。

---

## 7 · 落盘

写进**工作区根**，按契约第一节的布局。**顺序写死，不许反向**：

```
① kb/knowledge/（知识点） + sys/graph.json（关系图）
② kb/MOC/ 的机器区（由 aggregate.mjs 从「归属 + 图」聚合）
③ kb/MOC/ 的手写区（agent / 人写：主线、脉络、考点提示）
```

种子模板（`seeds/`）→ 填好草稿、给用户过目、再写：

| 种子 | 填什么 |
| --- | --- |
| `seeds/config.json` | 路径、分类（层级 / 解析规则 / 类值 / slug）、语言、git |
| `seeds/graph.json` | `用途` / `规则` / `coverage` / `edges` |
| `seeds/ledger.jsonl` | 先铺**本次范围内全部知识点**，`是否学习过 = 否`、`做对/总共出过 = 0`、`熟练程度 = null` |
| `seeds/errors.jsonl` | 只有头部说明行，**初始没有条目** |
| `seeds/error-taxonomy.json` | **保持为空** |
| `seeds/paper-format.json` | §5 收来的每条考试一格 |
| `seeds/state.jsonl` | 只有头部说明行 |
| `seeds/note.md` | 单篇知识点的骨架（frontmatter + 固定小节） |
| `seeds/moc.md` | 一份 MOC 的骨架（机器区标记 + 手写区） |

---

## 8 · 校验

```bash
node <skill>/scripts/validate.mjs <工作区根>     # 结构齐不齐
node <skill>/scripts/graph.mjs  check <工作区根> # 六项图校验
node <skill>/scripts/scan.mjs   <工作区根>       # 五项扫库
```

**结构齐 + 图六项全过 = 初始化完成。** 缺哪个补哪个，别靠感觉。

---

## 9 · Done

告诉用户：初始化完了，`mastery-loop` 之后会读这些文件；想改直接编 `sys/config.json`；**只有要换素材来源、改分类、或从头再来时才需要重跑本 skill**。
